## Уровни L1–L4

Документация построена как лестница: от того, *зачем* существует GRA, до того,
*в каком порядке* её развивать. Каждый уровень опирается на предыдущий и не
противоречит ему.

| Уровень | Документ | На какой вопрос отвечает | Как часто меняется |

| L1 Видение | [vision.md](vision.md) | Зачем GRA, для кого, чем она не является, как соотносится с индустрией | Редко, решением автора |
| L2 Концепция | [concept.md](concept.md) | Из каких понятий состоит GRA (масса, дистанция, полярность, информационные поля, гравитация, магнетизм) и на какие научные линии они опираются | При пересмотре конструктов |
| L3 Методология | [methodology.md](methodology.md) | Как формулируются и проверяются утверждения GRA, какие у них статусы, какие вопросы открыты | По итогам каждого цикла проверки |
| L4 Дорожная карта | [roadmap.md](roadmap.md) | В каком порядке GRA проходит ступени зрелости, какие треки (исследование, курс, партнёрства) и какие gate-критерии | Каждый цикл |

### Почему именно L1–L4, а не лестница Хаба

В Хабе используются две родственные лестницы: для методологий —
*Vision → Product Concept → Standards → Templates/Tools*, для продуктов —
*vision → product-concept → solution-concept → ADR*. GRA — не продукт и пока
не стандарт, поэтому уровни названы по форме исследовательской разработки:
видение → конструкты → метод → ступени зрелости. Соответствие лестницам Хаба
и обоснование —
[ADR-002](adr/2026-11-adr-002-methodology-form-and-l1-l4-structure.md).

## Источник истины (SSOT)

| Что | Где истина | Правило |
| --- | --- | --- |
| Текущее описание GRA (L1–L4), исследовательская модель, курс | **Этот репозиторий** | Изменения — через issue → PR; документ в репозитории важнее любой копии |
| Лучшие практики оформления, governance, работы с ИИ-агентами | [Хаб hybrid-Intelligence-lab](https://github.com/G-Ivan-A/hybrid-Intelligence-lab) | Не дублируются здесь; ссылки только абсолютными URL. Хаб задаёт практики, но не ограничивает развитие проекта |
| Глобальные исследования (за пределами GRA) | Хаб | Остаются в Хабе; здесь — ссылки |
| Внешние факты: стандарты, индустриальные практики, научные работы | Первоисточники из [sources-registry.md](sources-registry.md) | Утверждение о внешней практике без источника записывается как пробел |
| История замысла | Высказывания автора методологии (G-Ivan-A) | Пересказы ИИ-команд — контекст, а не истина; при расхождении прав автор |
| Программа курса | [Страница курса на сайте Технограда](https://technograd.moscow/event_page_new?669#programm_event) | Материалы курса в `education/` следуют опубликованной программе |
