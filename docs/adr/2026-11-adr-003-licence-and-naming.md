# ADR-003: Лицензия материалов и имя проекта

> Решение за автором методологии. Этот ADR фиксирует вопросы и рекомендацию;
> пока он в статусе `proposed`, действует текущее состояние.

## Контекст

1. **Лицензия.** Репозиторий создан с лицензией MIT (© 2026 Ivan Gulienko).
   MIT рассчитана на программный код. Основное содержимое репозитория — тексты,
   курс и иллюстрации. Для учебных и исследовательских текстов принято
   использовать лицензии Creative Commons. От лицензии зависят условия, на
   которых университеты и профессиональные организации могут использовать и
   цитировать материалы.
2. **Имя.** Текущее имя по README автора — *Gravity Reputation Architecture*.
   Документы июня 2026 рекомендовали бэкроним *Gravitational & Magnetic
   Reputation Architecture* и публичный слоган *Global Reputation Agreement*.
   Имя репозитория `aether-orbis-gra` связывает GRA с экосистемой Aether Orbis;
   курс называется «Введение в репутационный инжиниринг».

## Рекомендация

1. Лицензия: оставить MIT для кода в `tools/` и `tests/`, а для документов и
   курса выбрать **CC BY 4.0** (максимальная открытость для партнёров) или
   **CC BY-NC-SA 4.0** (запрет коммерческого использования без согласия
   автора). Выбор зависит от того, допускает ли автор коммерческое
   использование материалов курса.
2. Имя: сохранить *Gravity Reputation Architecture* как текущее. Магнетизм
   остаётся моделью внутри GRA. Слоган *Global Reputation Agreement* не
   использовать во внешних текстах, пока GRA не достигла ступени
   «методология»: слово *Agreement* предполагает консенсус, которого нет.
3. Имя репозитория не менять: оно отражает связь с экосистемой и уже
   используется в ссылках.

## Последствия

После решения автора: обновить `LICENSE` (или добавить `LICENSE-docs`),
`CITATION.cff`, README и этот ADR (статус `accepted` или `rejected`).
