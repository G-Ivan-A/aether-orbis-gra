# Академия ПСБ: реестр evidence и retrieval

## Как читать

Локальный пакет для review; разрешение внешней публикации не установлено
([A2](2026-11-08-issue-5-research-plan.md#рекомендации-и-вопросы-публикации)).
Срез и доступ ко всем строкам: **2026-11-08 UTC**. Дата доступа не является
датой публикации. «Без даты» означает отсутствие установленной даты документа.
Указанные ниже locators — разделы, пункты, номера страниц PDF (от 1), ID
карточек и поля API, а не нестабильные номера строк поискового сервиса.

● — фиксируется содержание источника, не истинность всех его заявлений;
◐ — интерпретация; ○ — гипотеза; ? — gap. VERIFIED — проверено названное
сведение/наличие; PARTIAL — самоотчёт, неполный доступ или предел сверки;
CONFLICT — источники расходятся. Реестр не содержит ФИО и контактов людей.
Ссылки ведут на первоисточники, в которых такие данные могут присутствовать.
