# Глоссарий GRA / GRA Glossary

> Текущие определения. Расширенный рабочий словарь исследовательской модели —
> [50-open-research.md §4](../methodology/research-program/50-open-research.md);
> словарь этапа I —
> [исторический документ](history/2026-06-20-glossary.ru-en.md) (устарел).
> Статусы: ● зафиксировано, ◐ интерпретация, ○ гипотеза.

| Термин (RU) | Term (EN) | Определение | Статус |
| --- | --- | --- | --- |
| GRA | Gravity Reputation Architecture | Авторская исследовательская концепция и разрабатываемая методология анализа репутационных, социальных и информационных связей / An author's research concept and a methodology in development for analysing reputational, social and information relationships | ● |
| Исследовательская модель GRA | GRA research model | Ядро, защитный пояс и эвристика GRA по Лакатошу; тело уровня L3 | ● |
| Масса (репутационная) | Reputation mass | Репутационный вес субъекта: совокупность его характеристик и положения в сети. Компоненты M1–M4. Не равна влиянию и не равна размеру | ○ |
| Влияние на решение | Influence on a decision (M5) | Проявление массы в конкретном решении; зависимая переменная, а не определение массы | ◐ |
| Дистанция | Distance | Многомерная разделённость субъектов: физическая, информационно-коммуникационная, социальная (доверие), ценностная, институциональная (D1–D5) | ○ |
| Полярность | Polarity | Направленность и характер отношения: положительный (+1), отрицательный (−1), нейтральный (0). Компоненты: знак, направленность, поток среды, время (P1–P4) | ◐ знак, ○ направление |
| «?» (нет данных) | Unknown | Статус данных, а не значение полярности: отношение неизвестно. Не заменяется нулём | ● правило |
| Информационное поле | Information field | Информационная среда или коммуникационный контур, меняющие эффективную дистанцию и интенсивность взаимодействий | ○ |
| Гравитация (репутационная) | Reputation gravity | Модель-гипотеза притяжения к центрам репутационного веса и влияния | ○ |
| Магнетизм (репутационный) | Reputation magnetism | Модель-гипотеза взаимного притяжения и отталкивания субъектов с учётом совместимости, интересов и характера отношений | ○ |
| Узел | Node | Субъект репутационного пространства | ● |
| Связь | Tie, relation | Отношение между узлами с характеристиками | ● |
| Контур (внутренний, внешний) | Internal / external contour | Группы узлов по отношению к субъекту: сотрудники, руководство, акционеры — внешние стейкхолдеры | ● |
| Точка влияния | Influence point | Узел, через который сигнал с наибольшей вероятностью влияет на решение; не то же, что аудитория | ◐ |
| ЛПР | Decision maker | Лицо, принимающее решение | ● |
| Provenance | Provenance | Происхождение факта: источник, дата, цитата | ● |
| VERIFIED / PARTIAL / CONFLICT | Verified / partial / conflict | Статус сверки источников: подтверждено, подтверждено частично, источники противоречат | ● |
| ● / ◐ / ○ | Fixed / interpretation / hypothesis | Шкала статусов утверждения | ● |
| Надёжность A–F, достоверность 1–6 | Source reliability A–F, information credibility 1–6 | Двухосевая оценка источника и сведения (по форме — «адмиралтейская» система) | ◐ |
| Гипотеза H0 | Baseline H0 | Исход объясняется охватом и тональностью упоминаний (оптика образа) | ● как практика |
| Гипотеза H1 | Hypothesis H1 | Формула основателя F(t) = (M_A × M_B) / D² × P(t) — один из кандидатов на форму связи | ○ |
| Операционализация | Operationalization | Способ измерить конструкт по доступным данным | — |
| Опровергающее условие | Falsification condition | Наблюдение, при котором гипотеза считается проигравшей; называется до сбора данных | ● правило |
| Соисследователь | Co-researcher | Участник, проверяющий гипотезы GRA на своём кейсе по протоколу | ● |
| Имидж-технологии | Image technologies | Методики работы с образом (цвет, форма, стиль, аксессуары). Изучаются на курсе отдельно; понятия GRA к ним не применяются | ● граница |
| Репутационный инжиниринг | Reputation engineering | Прикладная дисциплина управления репутацией на основе данных; предмет курса | — |
