# L3. Методология GRA: как проверяются утверждения

> Уровень L3 из [карты документации](README.md). Этот файл — обзор. Полное тело
> уровня — исследовательская модель
> [`methodology/research-program/`](../methodology/research-program/README.md).

## Форма

GRA сейчас — **исследовательский концептуальный фреймворк, развивающийся в
методологию**. Понятия и модели-гипотезы определены. Воспроизводимой процедуры
с проверенными измерениями пока нет. Обоснование выбора формы —
[аналитическая записка](analysis/2026-11-01-methodology-form-and-industry-positioning.md)
и [ADR-002](adr/2026-11-adr-002-methodology-form-and-l1-l4-structure.md).

Разработка идёт по циклам Design Science Research (DSR; Hevner et al. 2004;
Peffers et al. 2007). Структура исследовательской модели — по Лакатошу: **ядро**
пересматривается последним, **защитный пояс** операционализаций — в первую
очередь.

| Слой | Содержание |
| --- | --- |
| Ядро ○ | Структура связей между узлами (характеристики узлов, мера разделённости, знак и направление) объясняет исходы решений лучше, чем оптика образа (охват, тональность) |
| Защитный пояс ○ | Конкретные операционализации массы, дистанции и полярности; функциональная форма (H1–H6); правила агрегации |
| Эвристика ◐ | Из каждой аналогии выводить проверяемые отношения; каждую гипотезу снабжать опровергающим условием; каждую операционализацию сравнивать с альтернативой |

## Статусы утверждений

Каждое утверждение о GRA — в документах, на курсе, в письмах партнёрам — имеет
один из статусов. Статус повышается только по процедуре проверки, а не решением
автора.

| Статус | Значок | Значение | Пример |
| --- | --- | --- | --- |
| Зафиксировано | ● | Проверено по источнику или зафиксировано как замысел автора | Происхождение GRA; правило provenance |
| Гипотеза автора | ○ | Утверждение, для которого названо условие опровержения, но проверки не было | «Связь направлена: A→B ≠ B→A» (HP-D) |
| Концептуальная модель | ○ | Связка понятий, сформулированная как гипотеза о механизме | Гравитация, магнетизм, формула H1 |
| Требует операционализации | ○ | Понятие определено, способа измерения нет | Масса, оси дистанции, информационное поле |
| Интерпретация | ◐ | Применение известной теории к GRA | Знак связи по Хайдеру; оси дистанции по Boschma |
| Не разработано | ○, открытый вопрос | Нельзя даже сформулировать проверку | Агрегация массы холдинга; общая шкала дистанции |

### Текущий статус ключевых утверждений

| Утверждение | Статус |
| --- | --- |
| GRA — авторская гипотеза о структурном описании связей | ● |
| GRA — модель сбора и интерпретации данных, решения — вне GRA | ● (граница, заданная автором) |
| Масса многокомпонентна и отличается от влияния | ○ требует операционализации |
| Дистанция многомерна, минимум две независимые оси | ○ гипотеза HD1 |
| Знак связи +1/−1/0 | ◐ |
| Направленность связи и поток среды | ○ гипотеза HP-D |
| Гравитационная и магнитная модели | ○ концептуальные модели |
| Формула F(t) | ○ гипотеза H1, один из кандидатов |
| Структура связей объясняет исходы лучше охвата и тональности | ○ ядро, не проверено |
| Эмпирическая валидация | Не проведена |

## Процедура проверки гипотезы

Кратко ([полностью](../methodology/research-program/30-decision-framework.md#3-процедура-проверки-гипотезы)):

1. **S1.** Сформулировать гипотезу с измеримыми переменными.
2. **S2.** До сбора данных назвать условие, при котором гипотеза опровергнута.
3. **S3.** Назвать конкурирующую операционализацию и базовую линию H0.
4. **S4.** Собрать данные с provenance и статусами ●/◐/○.
5. **S5.** Сравнить гипотезу, альтернативы и H0 по критериям K1–K7:
   наблюдаемость, надёжность, объяснительная и прогностическая ценность,
   фальсифицируемость, экономность, этика и право.
6. **S6.** Независимо проверить ключевые факты и вывод.
7. **S7.** Записать исход, включая негативный, и вернуть урок в теорию.

Один успешный кейс повышает статус гипотезы с ○ до ◐ только для этого класса
кейсов, но не до ●.

**Запрещённые формулировки** (F1–F10): «физика доказывает GRA», «формула GRA»,
«дистанция — это обратное доверие», «GRA повышает выручку», «ИИ подтвердил
гипотезу» и другие. Каждой сопоставлена допустимая формулировка
([§2](../methodology/research-program/30-decision-framework.md)).

**Гейт для выводов ИИ-агентов** (G1–G6): источник, дата, статус, опровержение,
независимость, осторожность с выводами о личности. Вывод ИИ без гейта — не
свидетельство.

## Сбор данных

Практика, отработанная на курсе, — двухшаговый конвейер на открытых
источниках:

1. **Сбор** (промпт-фреймер): кто участвует в решении, какие связи видны в
   открытых источниках. У каждого факта — источник, цитата и статус.
2. **Верификация** (промпт-разведчик): сверка источников, разметка
   VERIFIED / PARTIAL / CONFLICT, список пробелов.

Рекомендации к действию в промпты сбора не входят: на этом шаге данные только
собираются. Этика: открытые профили и реестры — да; слитые базы, частная жизнь,
судебные споры частных лиц — нет. Материалы — в
[раздаточных материалах курса](../education/technograd-reputation-engineering/handouts/prompt-and-handout-registry.md).

## Ключевые исследовательские вопросы

| ID | Вопрос | Гипотезы и открытые вопросы модели |
| --- | --- | --- |
| R1 | Как операционализировать массу так, чтобы она не совпадала с влиянием? Подходят ли метрики центральности и репутационные индексы как компоненты? | M1–M4, T4; OQ-3, OQ-8 |
| R2 | Сколько осей дистанции нужно и независимы ли они? Можно ли их сводить в одно число? | HD1, H3; OQ-1, OQ-2 |
| R3 | Как наблюдать знак и направление связи, поток среды? | HP-D, H4; OQ-4 |
| R4 | Объясняет ли структура связей исходы лучше базовой линии «охват + тональность»? | Ядро против H0 (K3) |
| R5 | Какая функциональная форма связи лучше: формула H1, оцениваемые степени, модель радиации, порядковая модель? | H1–H6; OQ-5, OQ-9 |
| R6 | Чем магнетизм эмпирически отличается от гравитации? | Открытый вопрос; кандидат — гомофилия |
| R7 | Устойчивы ли структурные модели при переносе между контекстами; есть ли инерция массивных узлов? | HS, HM-I; OQ-6, OQ-7 |

**Порядок первой проверки** (по
[50-open-research.md](../methodology/research-program/50-open-research.md)):
R4 (структура против H0) → R3 (направленность) → R2 (независимость осей D1 и D2)
→ R1 (разведение массы и влияния) → R5 и R7 (нужны количественные данные и
временные ряды). R6 сначала требует определения, проверяемого на данных.

## Критерии качества метода

Принимаются как нормы из индустрии, а не изобретаются:

- прозрачность метода и источников, отказ от единой «магической» метрики —
  Barcelona Principles;
- прозрачность, согласованность, объективность — ISO 20671-1;
- надёжность разметки двумя независимыми исследователями (K2) — общая практика
  контент-анализа.
