# L4. Дорожная карта GRA

> Уровень L4 из [карты документации](README.md). Дорожная карта описывает
> **ступени зрелости и критерии перехода**, а не обещания по датам. Сроки
> зависят от появления соисследователей и данных. Конкретные работы ведутся в
> issues репозитория.

## Лестница зрелости

| Ступень | Что есть на ступени | Gate-критерий перехода на следующую | Где GRA сейчас |
| --- | --- | --- | --- |
| 0. Концепция | Авторская гипотеза, метафоры | Понятия определены, статусы утверждений размечены | Пройдена (2025–2026) |
| 1. Концептуальный фреймворк | Конструкты, модели-гипотезы, процедура проверки, открытые вопросы | (а) для массы и минимум двух осей дистанции есть операционализации, проходящие K1, K5, K7; (б) протокол проверки опробован минимум на трёх кейсах разных классов; (в) надёжность разметки двумя независимыми людьми измерена (K2) | **Здесь** |
| 2. Методология | Воспроизводимая процедура: шаги, роли, входы и выходы, критерии качества | (а) ядро проверено против H0 на серии кейсов с исходами, собранными после формулировки гипотез (K3, K4); (б) результаты, включая негативные, опубликованы; (в) есть независимая внешняя рецензия | — |
| 3. Проверенная методология | Методология с опубликованной эмпирической проверкой | Применение внешними командами без участия автора; повторяемые результаты | — |
| 4. Технология / де-факто стандарт | Инструменты, обучение, сообщество практиков | Консенсус профессионального сообщества; для формального стандарта — процедура признанного органа | Дальний горизонт |

Слова «стандарт», «технология», «доказано» не применяются к GRA, пока она не
достигла соответствующей ступени.

## Треки

### Трек A. Исследование

| Шаг | Содержание | Выход |
| --- | --- | --- |
| A1 | Опубликовать документацию L1–L4 и исследовательскую модель в отдельном репозитории | Этот репозиторий (сделано 2026-11) |
| A2 | Первая проверка R4 (структура против H0) и R3 (направленность) на кейсах соисследователей курса | Журнал кейсов, исходы по процедуре S1–S7 |
| A3 | Операционализация дистанции: проверить независимость осей D1 и D2 (R2) | Записка в `docs/analysis/`, обновление статусов |
| A4 | Операционализация массы: разведение массы и влияния; центральность и репутационные индексы как кандидаты (R1) | То же |
| A5 | Двойная разметка кейсов, оценка согласия разметчиков (K2) | Показатель надёжности |
| A6 | Определение магнетизма, проверяемое на данных (R6) | ADR о конструкте |
| A7 | Количественная проверка функциональной формы и инерции (R5, R7) | Отдельный исследовательский проект с партнёром, у которого есть данные |

### Трек B. Образование

| Шаг | Содержание |
| --- | --- |

### Трек C. Партнёрства

Цель — независимая проверка и совместные исследования с международными
университетами и профессиональными организациями. На 2026-11-01 партнёрств нет;
трек начинается с подготовки.

| Шаг | Содержание | Условие |
| --- | --- | --- |
| C1 | Подготовить пакет для партнёра: [overview.en.md](overview.en.md), статусы утверждений, научные основания, открытые вопросы | Готов в этом репозитории |
| C2 | Определить роли партнёров: (1) академическая рецензия и совместные исследовательские вопросы; (2) профессиональная организация — сверка с принятыми практиками измерения и оценки; (3) практики с данными — площадка для кейсов | — |
| C3 | Пилотное сотрудничество по одному вопросу (R2 или R4), а не по GRA в целом | После A2 |
| C4 | Юридическая проверка условий международного сотрудничества (санкционные и иные ограничения, обработка данных) | До любых обязательств |

**Чего не делать на ранних ступенях:** не публиковать «индекс» или рейтинг на
основе GRA, пока конструкты не операционализированы. Такой индекс выглядел бы
как результат, которого нет, и подорвал бы доверие партнёров.

### Трек D. Репозиторий и процесс

| Шаг | Содержание |
| --- | --- |
| D1 | Поддерживать соответствие практикам Хаба (профиль, валидаторы, ADR) |
| D2 | Фокус-группа (университет, профессиональная организация, слушатель) перечитывает внешние документы перед каждым значимым обновлением ([пример](audit/2026-11-01-focus-group-review.md)) |
| D3 | Решить открытые вопросы владельца: лицензия и имя ([ADR-003](adr/2026-11-adr-003-licence-and-naming.md)) |

## Риски

| Риск | Как снижаем |
| --- | --- |
| Метафора воспринимается как утверждение о законах | Запрещённые формулировки F1–F10; «как» в устной речи |
| Гипотезы выдаются за результат | Статусы утверждений; gate-критерии ступеней |
| ИИ-агенты расширяют границу GRA (например, на имидж-технологии) | Граница в [AGENTS.md](../AGENTS.md); гейт G1–G6 |
| Противопоставление индустрии отталкивает партнёров | Позиция «дополнение» в L1; сопоставление с практиками |
| Нет данных для количественной проверки | Порядковая модель H6 и качественные кейсы на первых шагах |
| Этика сбора данных | Только открытые источники; критерий K7 пороговый |
