# Образовательные курсы

Каталог курсов, построенных на языке GRA. Курс — первая практическая проверка
понятий GRA: масса, дистанция и полярность служат эвристикой вопросов и
ограничителями (guardrails) для ИИ-инструментов. Формула GRA в курсах не
используется: это непроверенная гипотеза.

## Правила для материалов курса

- Источник истины о программе — опубликованная страница курса на площадке.
  Названия дней и формулировки берутся оттуда.
- Учебные кейсы условные; реальные данные о людях в материалы не попадают.
- Сбор данных — только открытые источники; персональные данные обрабатываются
  по законному основанию.
- Утверждения о GRA в курсе не сильнее, чем в [docs/methodology.md](../docs/methodology.md#статусы-утверждений).
