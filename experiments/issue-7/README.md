# Evidence issue 7: подготовка встречи с Академией ПСБ

Прикладной пакет [именной карты и вопросов для встречи](../../docs/analysis/2026-11-09-issue-7-academy-decision-makers.md).
Граница — [решение владельца в PR #8](https://github.com/G-Ivan-A/aether-orbis-gra/pull/8#issuecomment-6736220932):
исключены данные других проектов. Профессиональные имена разрешены #7;
закупочные полномочия, частная жизнь и индивидуальные контакты не собирались.

| Артефакт | Происхождение / назначение |
| --- | --- |
| `evidence.json` | N01–N20 / P01–P10: прямые URL источников об Академии, локаторы, короткие цитаты, даты доступа и статусы. `previous` отсылает к источникам принятого пакета GRA #5, не к другим проектам |
| `preservation.json` | SHA-256 восьми записок GRA #5 и двух снимков каталога на принятом `c857c9c`; предшественники остаются на прежних местах |
| `validate_evidence.py` | Offline-контроль полноты, ссылок, границы источников/метаданных и сохранности предшественников; не проверяет истинность веб-страниц |

Схема 3 содержит только реестр Академии и baseline GRA. Хеши переноса,
выпускные манифесты, сценарии и снимки чужого сайта удалены. Подтверждение
внешнего факта — первоисточник по URL/locator, а не прежний исследовательский
файл. N01/N02/N03/N19 повторно проверены после уточнения владельца: индекс
N03 всё ещё расходится с полным документом N02. Также повторно открыты
программы N04/N16 и страницы организаторов N17/N18. Для остальных записей
сохранён описанный в `recheck` способ чтения первоисточника 09.11.2026;
новая проверка каждой из них в корректировке не заявляется.

Для N20 при первоначальном чтении проверены тип PDF, 13 страниц и текст;
размер и SHA оригинала — в записи N20. Полная презентация и индивидуальные
контакты в git не сохраняются. Даты неизвестных назначений/публикаций не
восстановлены из дат индексации.

Проверки без сети входят в существующий unittest CI:

```bash
python3 experiments/issue-7/validate_evidence.py
python3 -m unittest discover -s tests -p 'test_issue7_evidence.py'
```

Регрессии: чужой репозиторий в baseline; URL чужого проекта в источнике
или исследовательской записке; посторонние поля схемы, включая метаданные
переноса; посторонний файл пакета; потерянный источник/человек; пропущенный locator; повышение
индексного имени; выдуманный закупочный мандат; изменение предшественника.
Проверка ссылок по разрешённым издателям ограничена этой итерацией, не является
глобальной политикой репозитория и не доказывает релевантность любого текста
с того же домена. Смысл и полнота утверждений требуют чтения и review.
