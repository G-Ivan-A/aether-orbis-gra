# Исследовательская модель GRA

> Развёрнутое тело уровня L3. Сжатое изложение — [docs/methodology.md](../../docs/methodology.md),
> определения конструктов — [docs/concept.md](../../docs/concept.md).
> Модуль перенесён из Хаба (каталог `gra-research-program/`, снимок
> 32b5fa5) инструментом [`tools/import_from_hub.py`](../../tools/import_from_hub.py).
> Внутри файлов прежнее имя каталога упоминается как историческое.

Модуль оформлен по Reference Research Pattern Хаба: шесть файлов от введения
к открытым вопросам. Каждое утверждение имеет статус: ● зафиксировано,
◐ интерпретация, ○ гипотеза.

| Файл | О чём | С чего читать |
| --- | --- | --- |
| [00-introduction.md](00-introduction.md) | BLUF, происхождение, карта чтения | Всем |
| [10-theory.md](10-theory.md) | Ядро и защитный пояс по Лакатошу; принцип структурного соответствия; научные основания | Исследователю |
| [20-taxonomy.md](20-taxonomy.md) | Масса, дистанция, полярность; конкурирующие модели связи H0–H6 | Исследователю, преподавателю |
| [30-decision-framework.md](30-decision-framework.md) | Как формулировать, проверять и выбирать гипотезы; гейт G1–G6 для выводов ИИ-агентов | Исследователю, соисследователю |
| [40-practice-and-cases.md](40-practice-and-cases.md) | Сквозные кейсы курса, протокол соисследователя | Преподавателю, слушателю |
| [50-open-research.md](50-open-research.md) | Открытые вопросы, пробелы, словарь, источники | Партнёру, исследователю |

**Что не входит в модель.** Принятие решений (выбор стратегии, оптимизация
бизнес-результатов) — задача других моделей. Имидж-технологии к GRA не
относятся: на курсе для них используется только разметка достоверности
источников ([граница GRA](../../docs/concept.md#граница-gra)).
