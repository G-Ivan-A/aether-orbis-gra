# Бэклог aether-orbis-gra

Бэклог проекта: какие задачи есть, в какой последовательности и с каким
статусом. `AGENTS.md` требует сверяться с ним перед началом работы и обновлять
исполненную строку после неё. Бэклог создан задачей
[#3](https://github.com/G-Ivan-A/aether-orbis-gra/issues/3) (S-1 RFC Хаба #721,
шаг Ш2.3). Причина — анализ Хаба #713, A-1: правило есть, а бэклога не было.

Формат спринтов, поля и статусы взяты из
[инструкции по ведению бэклога Хаба](https://github.com/G-Ivan-A/hybrid-Intelligence-lab/blob/48ebe5230be87ca5bf8a08b385e296a2987e9958/ops/backlog-instruction.md)
без изменений. Отдельная инструкция в спице не заводится (Anti-Inflation).
Есть два локальных правила:

- **ID.** Задачи, принятые из Хаба, сохраняют ID Хаба (`B-230`). Тогда ссылки
  из PR, issue и аудитов Хаба остаются однозначными. Собственные задачи спицы
  получают ID `GRA-NNN`, потому что номера `B-NNN` выдаёт Хаб, и они бы
  столкнулись.
- **Источник принятой задачи.** Это permalink строки бэклога Хаба на коммите
  переноса. Ссылки внутри перенесённой строки, которые вели в домен Хаба
  `research/reputation-technologies`, заменены ссылками на копии в этом
  репозитории. Остальные ссылки на файлы Хаба закреплены на том же коммите.

## Спринт 29 Хаба: Задачи курса, принятые из Хаба

юридическую проверку формулировок кейсов, эмпирическую проверку гипотез HP-D и
